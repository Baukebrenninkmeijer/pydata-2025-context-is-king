LongMemEval Processing Flow - Step by Step
═══════════════════════════════════════════════════

📊 DATASET INPUTS
┌─────────────────────────────────────────────────┐
│  LongMemEval Focused CSV (306 questions)       │
│  └─ custom_id, focused_prompt, question        │
│                                                 │
│  LongMemEval Full CSV (306 conversations)      │
│  └─ custom_id, full_prompt                     │
└─────────────────────────────────────────────────┘
                        │
                        ▼

🔧 STEP 1: RUN EXTRACTION SCRIPT
┌─────────────────────────────────────────────────┐
│  python scripts/longmemeval_ground_truth_      │
│  extraction.py                                  │
│                                                 │
│  • Validates LongMemEval CSV structure         │
│  • Loads both focused and full datasets        │
│  • Initializes ChromaDB collection            │
└─────────────────────────────────────────────────┘
                        │
                        ▼

⚡ STEP 2: CHUNK FULL CONVERSATIONS
┌─────────────────────────────────────────────────┐
│  ConversationChunker                            │
│  • 500 tokens per chunk                        │
│  • 50 token overlap between chunks             │
│  • ~50,000 total chunks created                │
│                                                 │
│  Example: 113K token conversation →            │
│           ~230 overlapping chunks               │
└─────────────────────────────────────────────────┘
                        │
                        ▼

🗃️ STEP 3: STORE IN CHROMADB
┌─────────────────────────────────────────────────┐
│  ChromaDB Collection: longmemeval_conversations│
│  • Each chunk gets vector embedding            │
│  • Metadata: conversation_id, position, tokens │
│  • Optimized for similarity search             │
│                                                 │
│  Storage: chroma_longmemeval/ directory        │
└─────────────────────────────────────────────────┘
                        │
                        ▼

🎯 STEP 4: SIMILARITY SEARCH
┌─────────────────────────────────────────────────┐
│  For Each Focused Question:                     │
│  1. Query ChromaDB with focused_prompt          │
│  2. Filter to same conversation only            │
│  3. Get top candidate chunks                    │
│  4. Calculate similarity scores                 │
│                                                 │
│  Result: Ranked list of potentially relevant   │
│          chunks per question                    │
└─────────────────────────────────────────────────┘
                        │
                        ▼

📊 STEP 5: CONTENT OVERLAP METRICS
┌─────────────────────────────────────────────────┐
│  For Each Candidate Chunk:                     │
│                                                 │
│  • Jaccard Similarity                          │
│    └─ intersection(tokens) / union(tokens)     │
│                                                 │
│  • ROUGE-L Similarity (optional)               │
│    └─ Longest common subsequence              │
│                                                 │
│  • Token Containment                           │
│    └─ focused_tokens_in_chunk / total_focused │
└─────────────────────────────────────────────────┘
                        │
                        ▼

✅ STEP 6: RELEVANCE FILTERING
┌─────────────────────────────────────────────────┐
│  Apply Similarity Threshold (default: 0.65)    │
│  • Keep chunks above threshold                  │
│  • Sort by primary metric (jaccard/rouge_l)    │
│  • Take top N chunks per question (default: 5) │
│                                                 │
│  Output: Ground truth relevant chunks          │
└─────────────────────────────────────────────────┘
                        │
                        ▼

📋 STEP 7: GENERATE GROUND TRUTH JSON
┌─────────────────────────────────────────────────┐
│  data/longmemeval_ground_truth.json            │
│                                                 │
│  {                                              │
│    "metadata": {...},                          │
│    "questions": [                              │
│      {                                         │
│        "custom_id": "0a995998",                │
│        "question": "How many items...",        │
│        "relevant_chunks": [                    │
│          {                                     │
│            "chunk_id": "0a995998_chunk_7",     │
│            "primary_score": 0.78,              │
│            "overlap_metrics": {...}            │
│          }                                     │
│        ]                                       │
│      }                                         │
│    ]                                           │
│  }                                             │
└─────────────────────────────────────────────────┘

⚙️ KEY COMMANDS
═══════════════════════════════════════════════════

# 1. One-time setup: Extract ground truth
python scripts/longmemeval_ground_truth_extraction.py

# 2. Run Context Advantage with LongMemEval validation  
python experiments/context_advantage/context_advantage_experiment.py \
    --experiment-type longmemeval

# 3. Run Reranking Value with retrieval quality assessment
python experiments/reranking_value/run_experiment.py \
    --longmemeval-ground-truth data/longmemeval_ground_truth.json
